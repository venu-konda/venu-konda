Full-Duplex IPC with Named Pipes

Linux · mkfifo · open / read / write

Two independent processes chatting through a pair of FIFOs (named pipes), one for each direction. Start both and watch the open() calls rendezvous, then type messages: write() on one side wakes the blocked read() on the other. Kill a process to see the peer get end-of-file.
