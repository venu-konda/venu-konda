ESP32 Smart Irrigation Controller

ESP-IDF · FreeRTOS · NVS · MQTT GitHub ↗

The control logic of my ESP32 irrigation firmware running against a simulated plot: a capacitive soil-moisture probe (raw ADC counts with dry/wet calibration), a pump on a relay, a tank float switch and a hardware fail-safe timer. The same state machine, safety limits, UART console commands and MQTT JSON as the real device. Simulated time runs at the speed you choose.
