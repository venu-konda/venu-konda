C Preprocessor from Scratch

C · Make · single dynamically resized buffer GitHub ↗

My preprocessor reads a .c file into one heap buffer and runs three passes over it, producing the .i file: comment removal, #include expansion and object-like #define replacement. This page runs the same three stages in JavaScript on an editable source file and virtual header files, so you can see what each pass does to the buffer.

readFromFile()→removeComments()→fileInclusion()→macroReplacement()→writeToFile()
