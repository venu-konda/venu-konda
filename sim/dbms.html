Client–Server Student DBMS

Linux · TCP/IP sockets · C

A TCP server holding a student table and a command-line client talking to it over a socket, as in my Linux system-programming project. Type commands in the client; each one becomes a request line on the wire, the server parses it, touches the table and sends a response back. The socket calls on both sides are logged in order.
